# ADEl V1
A lightweight, multilingual browser toolkit (Arabic/French/English).

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Google Chrome.
3. Most tools run locally in your browser. QR generation loads QRCode.js from a CDN and therefore needs internet access.

## Publish free
### GitHub Pages
1. Create a GitHub account and a new public repository named `adel`.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Wait for the published URL shown in Pages.

## Notes
- Image compression converts images to JPEG; transparent backgrounds are not preserved.
- No accounts or server are required in V1.
- Before commercial launch, add a privacy policy, terms, accessibility checks, analytics only with appropriate consent, and test on mobile browsers.
